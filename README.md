# atria-assets

Public assets for the [Atria](https://marketplace.visualstudio.com/items?itemName=Lovervoid.atria)
marketplace page.

The extension's own repository is private, so `vsce` cannot rewrite a relative
image path into anything that resolves. Everything the listing has to reach
lives here instead, and the README links it by absolute URL: nothing to
remember at publish time, and a broken link shows up in any markdown preview
rather than on the published page.

- `images/` - the screenshots the marketplace page carries.
